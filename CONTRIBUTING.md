# Contribuir com a LuverControl

Leia o README e as instruções do repositório. Use os modelos de issue para
relatar falhas ou propor melhorias, incluindo versão, ambiente e passos de
reprodução. Remova dados pessoais e credenciais dos anexos.

Crie uma branch para cada alteração e abra um pull request para a branch
principal. Descreva o problema, a mudança e as verificações executadas.
Mantenha testes existentes e acrescente cobertura quando houver uma mudança
de comportamento que precise ser protegida. Aguarde os checks e a revisão.

Para software FRC, mantenha autorização explícita de operação, parada e
limites físicos. Diferencie testes simulados e testes com hardware real.
Ajustes de mecanismo e do número da equipe pertencem a cada robô.

Problemas de segurança seguem a [política de segurança](SECURITY.md).
A convivência segue o [código de conduta](CODE_OF_CONDUCT.md).
