# LuverControl 10298

Software para **FIRST Robotics Competition (FRC)**: controles, motores,
visão, telemetria, planejamento de caminhos e ferramentas de ajuste.

## Comece pela LuverLib

A [LuverLib](https://github.com/LuverControl/LuverLib) reúne módulos Java para
WPILib 2026 e o AutoPrecision, supervisor Python de ensaios PID para NEO/SPARK MAX.

- [Instalação e documentação](https://github.com/LuverControl/LuverLib#começar-e-instalar)
- [Versões para download](https://github.com/LuverControl/LuverLib/releases)
- [Builds e testes automatizados](https://github.com/LuverControl/LuverLib/actions)
- [Reportar um problema](https://github.com/LuverControl/LuverLib/issues/new/choose)
- [Contribuir](https://github.com/LuverControl/LuverLib/blob/main/CONTRIBUTING.md)

Trabalhamos com revisão por pull request, testes em simulação e validação
física feita pela equipe. Os parâmetros de cada mecanismo são definidos e
confirmados no robô correspondente.
